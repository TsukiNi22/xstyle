## Packages {#packages}

The same packages exist as RPM (Fedora), DEB (Debian / Ubuntu) and Arch (pacman, `.pkg.tar.zst`): same names, content and dependencies. They are signed and published on the `gh-pages` branch ([install them](page:getting-started#packages)).

| Package | Content |
|---|---|
| `xstyle` | installs the default package (`xstyle-op`) |
| `xstyle-op` | the executable compiled with the optimization options |
| `xstyle-db` | the executable compiled with the debug options (debugging only) |
| `xstyle-as` | the executable compiled with AddressSanitizer (debugging only) |

> [!WARNING]
> The three variants install the same `/usr/bin/xstyle`: only one of them at a time.

## Pre-release {#pre}

Every package has a pre-release named `<package>-pre`, built from a tag `vX.Y.Z-<suffix>` or a commit containing `[build]`. A `-pre` package is obsoleted by any stable package of the same version or higher; only the 5 last versions of each `-pre` are kept in the repository.

## Shell completions {#completions}

Every package installs the completion of the shells (flags, rule codes, severities, languages, comma lists), generated by `xstyle --completion bash|zsh|fish`:

```text "Files"
/usr/share/bash-completion/completions/xstyle
/usr/share/zsh/site-functions/_xstyle
/usr/share/fish/vendor_completions.d/xstyle.fish
```

| Shell | Loaded |
|---|---|
| bash | on demand by bash-completion |
| zsh | in new shells (`compinit`) |
| fish | on demand |
